# Engelsoft Nodarion 1.15.5

Dieses Veröffentlichungsrelease verbessert die Installation und Präsentation
von Engelsoft Nodarion. Das zugehörige Frontend trägt weiterhin die Version
**1.18.5**.

## Neu

- Direkte Ein-Klick-Einrichtung als benutzerdefiniertes HACS-Repository
- Erweiterte README-Galerie mit Teilnehmerübersicht, AdGuard DNS-Live und
  KI-Netzwerkanalyse
- Anonymisierte Beispieldaten in allen öffentlich gezeigten Netzwerkansichten
- Aktualisierte Dokumentation für die geplante Aufnahme in den HACS-Katalog

An der Netzwerküberwachung selbst wurden in diesem Release keine funktionalen
Änderungen vorgenommen. Nach dem Update ist ein Neustart von Home Assistant
erforderlich.
