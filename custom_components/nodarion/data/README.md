# Lokale MAC-Herstellerdaten

`mac_vendors.json` enthält MAC-Präfixregistrierungen für den vollständig
lokalen Herstellerabgleich in Engelsoft Nodarion. Die Datei wurde am
31. Juli 2026 aus der frei angebotenen JSON-Datenbank von
https://maclookup.app/downloads/json-database erzeugt.

Nodarion sendet beim Lookup keine MAC-Adresse und keine anderen Gerätedaten an
einen externen Dienst. Längere MA-S- und MA-M-Präfixe werden vor MA-L geprüft.
Lokal verwaltete beziehungsweise randomisierte MAC-Adressen werden absichtlich
nicht einem Hersteller zugeordnet.
