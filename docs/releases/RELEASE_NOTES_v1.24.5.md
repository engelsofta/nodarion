# Nodarion 1.24.5 — One version, everywhere

> **What you install is now exactly what Nodarion shows.**

## Deutsch

Die Versionsanzeige im Nodarion-Panel war noch fest auf `1.24.1` gesetzt,
obwohl bereits eine neuere Integration installiert war. Version 1.24.5 gleicht
diese Anzeige mit dem Manifest ab und aktualisiert außerdem die Versions-Badges
in beiden README-Dateien.

Ein neuer Regressionstest stellt sicher, dass angezeigte und installierte
Version künftig nicht wieder auseinanderlaufen.

---

## English

The Nodarion panel still exposed a hard-coded `1.24.1` even when a newer
integration was installed. Version 1.24.5 synchronizes that display with the
manifest and updates the release badges in both README files.

A new regression test prevents the displayed and installed versions from
drifting apart again.

## Versions

- Integration: `1.24.5`
- Frontend: `1.29.4`
