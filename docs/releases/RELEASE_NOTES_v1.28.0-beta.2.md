## Network dependency fix

Nodarion now declares Home Assistant's `network` component as a dependency for the IPv4 subnet suggestion during initial setup. This addresses the Hassfest validation failure in beta 1.

This beta includes the [Marketplace quick start, first-scan improvements and new branding](https://github.com/engelsofta/nodarion/releases/tag/v1.28.0-beta.1). Enable pre-releases for Nodarion in the Home Assistant Marketplace, select **v1.28.0-beta.2**, and restart Home Assistant after updating.
