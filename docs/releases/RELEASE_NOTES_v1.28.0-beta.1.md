## Marketplace quick start and a new look

- Start with the new [Marketplace quick start](https://github.com/engelsofta/nodarion#installation) in English or [German](https://github.com/engelsofta/nodarion/blob/main/README.de.md#installation).
- Confirm the suggested IPv4 subnet when Nodarion detects one eligible network, or enter your subnet manually. FRITZ!Box and AdGuard Home are optional.
- Open Nodarion from the sidebar to see the first scan run in the background. If the scan finds no devices or fails, the panel shows what to check and how to retry.
- Look for the new gold radar icon in Home Assistant. The GitHub README uses a matching wordmark in light and dark mode.

To try this beta, enable pre-releases for Nodarion in the Home Assistant Marketplace, select **v1.28.0-beta.1**, and restart Home Assistant after updating.
